# FinSight AI — API

The running API serves its full OpenAPI schema at `GET /docs` (Swagger UI) and
`GET /openapi.json`. This page is the map; the schema is the contract.

Every collection route answers both with and without a trailing slash
(`/goals` and `/goals/`), because the Next.js proxy strips trailing slashes.

## Auth

With `REQUIRE_AUTH=true` (production), every user route expects
`Authorization: Bearer <supabase_access_token>`. Rows are scoped to the caller in
the app layer and again by Postgres RLS ([ADR 0007](./adr/0007-rls-app-scoping.md)).

| Method | Path | Notes |
|--------|------|-------|
| POST | `/auth/sync` | Upsert the local user from the Supabase token; provisions demo data for empty accounts |
| POST | `/auth/bootstrap` | First-run setup for a new account |
| GET / DELETE | `/auth/me` | Profile / delete account and all data |
| GET | `/auth/me/export` | Full data export (PIPEDA access request) |
| GET / DELETE | `/auth/me/profile` | Learned advisor profile / reset it |
| POST | `/auth/me/send-digest` | Email the weekly digest now |

## Chat

Each turn is routed to a tier ([ADR 0005](./adr/0005-model-routing.md)):
**basic** goes to Groq `openai/gpt-oss-20b`, **heavy** goes to Claude
`claude-sonnet-4-6`. `GET /capabilities` reports the live routing under `ai.routing`.

| Method | Path | Notes |
|--------|------|-------|
| POST | `/chat` | Server-sent events: `session`, `status`, `token`, `done` (reply, citations, evidence) and `error` |
| GET | `/chat/sessions` | History, newest first; `reply_pending` marks a turn still being answered |
| GET / PATCH / DELETE | `/chat/sessions/{session_id}` | Messages with evidence / rename or pin / delete |

Session ids are generated by the client, so a new chat is addressable before the
first token arrives. Dollar amounts in replies carry evidence tags such as
`[[$412.30|ev_17]]`, which the UI renders as clickable source chips.

## Regenerating TypeScript types

The frontend keeps hand-written types in `frontend/lib/types.ts`. To diff them
against the live schema:

```bash
cd frontend
npx openapi-typescript http://127.0.0.1:8000/openapi.json -o lib/api-types.d.ts
```
